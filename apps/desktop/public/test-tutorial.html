🎓ISBN Tutorial Test Guide

Panduan lengkap untuk test Interactive Tutorial

🚀Quick Start

App sudah running! Jika belum, jalankan: pnpm tauri:dev

1Buka Aplikasi

Aplikasi Perpustakaan sudah terbuka di desktop kamu (Tauri window)

2Login & Navigate

Login dengan credentials default, lalu klik menu "Buku" di sidebar

3Buka DevTools

Tekan F12 atau Ctrl+Shift+I untuk buka DevTools

4Clear localStorage

Di Console tab, ketik:

localStorage.removeItem('isbn-tutorial-completed')

Lalu refresh page: F5 atau Ctrl+R

5Tutorial Muncul!

Tunggu 1 detik, tutorial modal akan muncul otomatis dengan welcome screen

✅Manual Test Checklist

  • Tutorial muncul otomatis setelah clear localStorage & refresh
  • Modal overlay (background gelap) muncul
  • Welcome screen dengan title "🎉 Fitur Baru: ISBN Scanner"
  • Button "Skip Tutorial" dan "Mulai" ada
  • Klik "Mulai" → navigate ke step 2
  • Arrow pointer ke tombol "Impor via ISBN" (highlight)
  • Bisa klik "Kembali" untuk previous step
  • Bisa klik "Lanjut" untuk next step
  • Total 7 steps (Welcome → Button → Modes → Preview → Auto-fill → Tips → Finish)
  • Klik "Mulai Scan" di step terakhir → ISBN Scanner modal auto-open
  • localStorage set: isbn-tutorial-completed = 'true'
  • Tombol "Tutorial ISBN" ada di halaman Buku
  • Klik "Tutorial ISBN" → tutorial replay dari awal
  • Setelah complete, refresh page → tutorial tidak muncul lagi
  • Styling bagus (smooth animations, modern design)

🎯Expected Behavior

First-Time User Flow

  1. User buka halaman Buku (pertama kali)
  2. Delay 1 detik
  3. Tutorial modal muncul otomatis
  4. User follow 7 steps atau skip
  5. localStorage set: isbn-tutorial-completed = 'true'
  6. Jika complete → ISBN Scanner auto-open

Returning User Flow

  1. User buka halaman Buku
  2. Tutorial tidak muncul (sudah pernah complete)
  3. Tombol "Tutorial ISBN" tersedia untuk replay

🐛Troubleshooting

Tutorial tidak muncul?

Check di Console:

// Check localStorage localStorage.getItem('isbn-tutorial-completed') // Should return: null (belum complete) atau 'true' (sudah complete) // Force clear localStorage.clear() location.reload()

Error di Console?

Screenshot error message dan check:

  • Apakah Shepherd.js loaded? Check Network tab
  • Apakah CSS loaded? Check Elements tab
  • Apakah ada conflict dengan library lain?

Button tidak ter-highlight?

Check di Console:

document.querySelector('[data-tour="isbn-import-button"]') // Should return: <button> element

🎉Success Criteria

Tutorial dianggap berhasil jika:
  • ✅ Modal muncul otomatis untuk first-time user
  • ✅ Semua 7 steps bisa di-navigate

  • ✅ localStorage persistence bekerja

  • ✅ Auto-open ISBN Scanner setelah complete
  • ✅ Styling smooth & responsive
